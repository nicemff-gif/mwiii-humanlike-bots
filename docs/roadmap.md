# 研发里程碑

| 阶段 | 交付 | 退出条件 |
| --- | --- | --- |
| M0 工程基础 | 独立 GitHub 仓库、主分支保护、CI、需求与 ADR | 检查通过，公开内容符合范围 |
| M1 工具链与观测 | 锁定编译器、原创 GSC 观察探针、产物摘要、部署/回退设计 | 本地与 CI 编译、反编译检查通过；游戏加载另记实测 |
| M2 有限感知与记忆 | 观察输入、最后目击位置、过期与搜索状态 | 固定场景中丢失视线后不使用实时隐藏坐标 |
| M3 统一动作所有权 | 原生任务接管边界、中断、清理、换弹与撤退 | 各动作无争夺控制，出生/死亡/结束清理完整 |
| M4 最小交战闭环 | 发现、交火、失视、搜索、放弃 | 多次同场景录像与记录支持验收 |
| M5 玩家风格与团队 | 能力差异、侧翼、支援与目标玩法 | 自然度、强度、模式表现分别可调 |
| M6 扩展与发布 | 更多地图/模式、性能、兼容性 | 回归矩阵与版本说明完整 |

阶段按验证门槛推进，不承诺未实测的游戏行为。CI 成功不自动完成需要游戏实测的阶段。
