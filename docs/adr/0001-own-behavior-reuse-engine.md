# ADR 0001：自主行为核心，复用游戏底层能力

- 日期：2026-10-20
- 状态：Accepted

## 背景

本地研究发现，现有两个人机补丁会同时控制移动目标、难度、姿态、武器和装备。部分设计通过实时目标位置、传送、补弹和伤害倍率维持交战，难以直接用参数调整实现一致的信息限制和动作所有权。

## 决策

自主编写行为核心，复用 MWIII 的导航、机器人实体、碰撞、动画及武器接口；LUMEN 用作外部脚本加载环境。先验证接口与生命周期，再接管行为。

```text
Runtime adapter → observable observations → perception and memory
                                             ↓
                                      decision selection
                                             ↓
                                  action ownership / cleanup
                                             ↓
                                engine movement / weapon APIs
```

运行时适配器可访问引擎实体，但决策层只接收经过感知规则过滤的观察结果。引擎对导航环境的知识不等于决策层可以知道隐藏敌人的位置。

旧补丁仅作为本地研究与实验对照。新仓库从独立初始提交开始，不继承游戏安装仓库的二进制历史。

## 后果

需要建立编译、观测、运行验证和回退流程。首版集中普通 MP，小范围验证闭环。每个接口标记为文献参考、编译验证或运行验证，避免把存在函数名当成当前版本可用的证据。
