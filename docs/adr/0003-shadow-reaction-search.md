# ADR 0003：先验证决策意图，再接入动作

状态：已采用；游戏验证未完成。

## 决定

在感知和记忆之上增加纯决策模块，只接收显式时间、受过滤的记忆、当前一批采样的目标编号与可见性结果。模块返回独立意图，不读取引擎实体或世界坐标，不调用导航、瞄准、开火等接口。

状态为 `idle`、`reacting`、`tracking`、`searching`。对应意图为 `none`、`wait`、`observe`、`search`；`observe` 不代表可以开火。任何实际动作仍需未来的统一控制权和运行适配器。

首次可见进入 reacting。反应期限到达后，还需要一次当时可见且与记忆时间一致的正样本才能进入 tracking。负样本中断尚未完成的确认；已确认目标失视后则进入 searching，只提供最后目击位置。搜索期限取搜索预算与记忆过期时刻中的较早者。记忆过期、传感样本过旧、观察者生命周期重置和时钟异常均不能保留旧确认。

未采样不是负样本；使用独立的样本陈旧期限处理轮转调度。目标仍有效时保留焦点，搜索时可响应新的可见目标，重新发现和切换都重新经历反应期。同批可见目标以编号决定稳定顺序，仅作为本阶段的确定性策略，不代表战术优先级。

## 验证和限制

人工游戏验证按使用者时间安排延期；延期不会把 `not_run` 改成通过。共享场景由 Python 参考模型执行，并生成调用实际 GSC 核心的原生断言。后者目前仅完成编译和反编译检查。决策意图接入观察调度与诊断后仍未获得游戏兼容性证据。

当前参数是工程初值，尚未以玩家行为数据校准。状态机和确定性回放可以在游戏反馈前继续开发；实际控制权接管、引擎行为兼容及真人化效果需要另行验证。不得根据本 ADR 宣称交战闭环或 M3 动作仲裁已经交付。
