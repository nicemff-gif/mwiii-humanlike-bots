# ADR 0002：先在小队 TDM 中观察有限记忆

- 日期：2026-10-20
- 状态：Accepted

## 决策

首版目标明确为常规小地图多人 TDM。首先交付只读感知与记忆，保持原有行为控制；原生模式白名单、连接人数上限和独立开关共同限制运行范围。

记忆模块不接触实体。引擎适配器只在视角与射线检查通过后导出可见位置，隐藏移动不成为领域输入。每个观察者独立、有限容量、有限期限，失去视线后不追踪实时坐标。

Python 模型作为可执行设计参考，同一组场景另外生成 GSC 自测代码。两者分开记录执行状态；原生自测失败时停止自己的观察任务。构建清单包含全部模块和场景生成输入的摘要。

## 后果

无需提前终止原版机器人任务即可检查感知与记忆接口，降低同时调试策略、控制权和游戏接口的复杂度。代价是当前观察结果不会改变对局行为，且游戏内的原生断言、视线语义和生命周期仍需独立实测。
