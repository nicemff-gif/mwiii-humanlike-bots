# 需求与验收

## 产品目标

人机能依据自身获得的信息行动，形成连贯且有差异的玩家行为。强度、自然度、模式目标参与和性能分别评估。

## 模式顺序

第一版只适配常规小队团队死斗（TDM），当前白名单为原生 `war`、团队对局、连接实体数 1–12。未知标识、非团队和较大对局直接停止自己的观察任务。白名单是当前代码边界，不是所有本地版本均已验证的兼容声明。

后续按占领／据点争夺、爆破的顺序增加模式策略。自由混战、特殊玩法、大规模多人、战区、僵尸及战役另行适配。通用感知、记忆和动作核心与模式目标分离。

## 行为约束

1. 可见目标使用引擎提供的视线结果；不可见敌人的实时位置不进入决策输入。
2. 目标记忆记录最后目击位置和时间，随时间失效；搜索使用记忆而非隐藏实体坐标。
3. 移动、视角、射击、姿态和装备的控制权由统一仲裁器管理，动作可被明确中断和清理。
4. 反应、瞄准和风险偏好有可复现的个体差异，随机种子与参数写入实验记录。
5. 普通弹药、伤害和生命规则保持为实验基线；辅助功能必须独立列出。
6. 自然度实验不使用维持交战密度的隐蔽传送；卡住恢复单独设计、记录和评估。

## 首个垂直切片

同一张普通多人小地图的 TDM、固定人数下验证：发现敌人 → 确认目标 → 交火/换位 → 丢失视线 → 最后位置搜索 → 继续交战或放弃。

成功标准是可观察的状态和动作变化，而非仅有击杀数提高。当前尚无已通过游戏实测的实现。
