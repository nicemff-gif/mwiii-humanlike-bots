# 研究来源与基线

本项目来自本地 MWIII 安装仓库的静态研究，原仓库独立保留：

- `a2a07b9`：LUMEN、中文语言与菜单，无两个人机补丁，可作为对照环境参考。
- `768b48b`：叠加 BOTS OVERHAUL 的阶段。
- `a9c1b51`：再叠加 LUMEN BOTMOD 的阶段。

这些标识仅说明本地研究来历，不是本新仓库的 Git 祖先，也不表示游戏文件可从本仓库重建。原仓库的运行变量和个人设置未被完整版本管理，实验仍须显式记录。

公开技术参考：

- [Atian Tools](https://github.com/ate47/atian-cod-tools)：GSC 编译和反编译工具；构建时固定发布版本与摘要。
- [MWIII 公开反编译资料](https://github.com/ate47/mwiii-source)：接口和原版脚本结构的研究参考，转储日期为 2024-11-07，不能代表本地版本逐字一致。

第三方反编译源码、补丁、LUMEN 程序与游戏资源不作为本项目原创代码收录。原始研究材料保存在使用者本地。
